🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project demonstrates DOM manipulation, event handling, and basic game logic in JavaScript.

🚀 Features
Two-player game (X vs O)
Winner detection 🎉
Draw detection 🤝
Reset & New Game functionality
Clean and responsive UI
Reset button hides after game ends (UX improvement)

🛠️ Technologies Used
HTML – Structure of the game
CSS – Styling and layout
JavaScript – Game logic and interactivity

🎯 How to Play
The game starts with Player O
Players take turns clicking on empty boxes
First player to align 3 symbols (row / column / diagonal) wins
If all boxes are filled and no one wins → Game Draw
Click New Game to start again
